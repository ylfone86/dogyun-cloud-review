# DogYun测评：弹性计费真香，机龄计划让香港云服务器越用越省

最近这几年折腾云服务器的人越来越多，预算紧、需求杂、又怕被坑，挑来挑去就那几个名字。DogYun（狗云）算一个绕不开的选项——2019 年从老牌虚拟主机业务里独立出来的新品牌，主打 KVM 架构、按小时计费、多机房多线路，定位很清楚：给那些想要灵活配置又不想花冤枉钱的人。这篇 DogYun测评 就来聊一聊，这家定位「高性价比」的国产云服务商，到底值不值得入手。

## 一、先搞清楚：DogYun 到底卖什么

DogYun 的产品线其实分得很清晰，三条主线，定位完全不一样：

- **弹性云服务器**：可以随时调整 CPU、内存、硬盘、带宽、IPv4 路线，按小时计费，用多少扣多少。简单说就是「云原生」那一套思路，适合流量不稳定的项目。
- **经典云服务器**：传统的包年包月固定套餐，开通后不能改配置，胜在价格便宜、起步门槛低，是大部分个人站长入门的首选。
- **独立物理服务器**：整台物理机独享，性能、带宽、IO 都不受虚拟化限制，适合对资源有硬需求的高并发业务。

这三种产品共用一套自研的「Dudu 控制面板」，中文界面，重装系统、换 IP、切线路、调配置全部自助完成，几乎不需要提工单。这一点对不爱折腾工单的人来说，体验是加分项。

机房方面，目前覆盖香港（KC、MG、CLD 三个机房）、韩国首尔、日本大阪、美国洛杉矶、美国圣何塞、重庆，欧洲有德国和荷兰节点。线路主要是 CN2 GIA、CMI、CUII（联通 AS9929）、BGP 优化、IIJ 等几种，对国内三网访问都做了优化。

## 五、网络实测：香港机房到底快不快

DogYun测评 绕不开线路实测。综合各家第三方测评数据：

- **延迟**：香港机房到国内三网普遍 15–30ms，日本 50–80ms，韩国 30–60ms，美国洛杉矶 150–180ms。香港精品线路在 Ping 上能比经典云的 163 线路再快几毫秒。
- **晚高峰速度**：香港精品/优化线路基本能跑满标称带宽，国际线路在高峰期会有一定波动，但比纯国际线路稳得多。
- **IP 质量**：香港-KC、香港-MG 等机房实测 V4、V6 均为香港原生 IP，解锁流媒体能力不错。
- **硬件跑分**：升级到 EPYC 7003 系列之后，CPU 跑分有明显提升；磁盘 IO 在 KC 机房因为部分老款 480GB MLC SATA 6Gbps 盘的限制，没有跟上 CPU 的进步，这点要注意。

线路选择上，香港-KC 主推三网优化（电信 CN2 GIA + 联通 CUII + 移动 CMI），香港-MG 走 BGP 优化或国际线路（带宽大、性价比高），香港-CLD 走优化 BGP。美国-LA 自带 20G DDoS 防御，重庆走联通骨干并自动白名单。
